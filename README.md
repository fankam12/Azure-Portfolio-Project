
# Azure Portfolio Project — Home lab Infrastructure

This is a step-by-step Azure cloud infrastructure project designed to reinforce my learning for the **AZ-104: Microsoft Azure Administrator** certification. The project is built using **Azure PowerShell CLI** and deployed via the Azure Portal.

## 🔍 Project Overview

The goal is to simulate a scalable and secure enterprise-like Azure environment under a dedicated **Resource Group: `HomeLabRG`**. This portfolio project will grow in **phases**, beginning with a small virtual network and multiple VMs, and expanding to include:

- Load balancers
- Web application hosting
- Static resume website
- Azure Active Directory users (4–8 simulated employees)
- NSGs, VM extensions, and secure access configurations
- Optional containerization (AKS, ACR)

The entire project will be **documented in GitHub**, including architecture diagrams built with **Draw.io**, PowerShell scripts, and deployment guides.

## 🎯 Project Goals

- Reinforce AZ-104 certification topics through practical application
- Build confidence working with Azure resources and automation tools
- Demonstrate cloud engineering skills to potential employers
- Simulate a realistic cloud infrastructure environment with a focus on networking, identity, and scalability

## 🧱 Technologies Used

- Azure PowerShell CLI (primary)
- Azure Portal
- Bash (supplementary)
- Draw.io (for infrastructure diagrams)
- GitHub (documentation and version control)
